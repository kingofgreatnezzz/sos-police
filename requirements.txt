# =============================================================================
#  Emergency Response and SOS Location Tracking System
#  Nigeria Police Force - Enugu State Command
#
#  ONE codebase, TWO modes:
#     MODE 1  Citizen SOS App    - mobile panic button, no login
#     MODE 2  Police Command     - control-room dashboard with live alarm
#  Both are served by app.py and share data/sos_emergency.db
#
#  Install with:   pip install -r requirements.txt
#
#  NO PAID SERVICES AND NO NEW PACKAGES ARE REQUIRED.
#  The following are used from the Python STANDARD LIBRARY only:
#     sqlite3   - the database engine (no server to install)
#     hashlib   - PBKDF2 password hashing
#     hmac      - constant-time password comparison
#     math      - the Haversine great-circle distance formula
#     wave      - generates the alarm and confirmation sounds (sounds.py)
#     struct    - 16-bit PCM sample packing for those sound files
#     array     - memory-efficient sample buffers
#     datetime  - timestamps
# =============================================================================
